Connecting your AWS account

Five minutes, read-only access, no changes to your infrastructure.

1. Log in to the AWS Console

Go to console.aws.amazon.com and log in with your usual admin account.

2. Open IAM → Users → Create user

Search "IAM" in the top search bar. Under Users, click Create user and name it clearly:

xenkloud-pulse-readonly

3. Attach read-only permissions

Choose "Attach policies directly" and check these three:

ReadOnlyAccess (Billing) · AmazonEC2ReadOnlyAccess · CloudWatchReadOnlyAccess

4. Generate an access key

Open the new user → Security credentials tab → Create access key → choose "Third-party service." Copy both the Access key ID and Secret access key immediately — AWS only shows the secret once.

5. Send it to us securely

Reply to your confirmation email with the keys, or use the secure upload link included in it. Avoid sending credentials in plain, unencrypted messages where possible.
